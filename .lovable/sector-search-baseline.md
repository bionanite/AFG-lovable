## Implemented decisions
Use the eight existing sector URLs; no duplicate service landing pages or bulk new articles. Add scoped buyer questions and preparation lists, link three existing relevant guides per sector and link guides back to applicable sectors. Retain the existing visual design and videos. Preserve valid FAQ data, with added questions shared between rendered answers and schema. Add WebPage/provider/service relationships, not unsupported credential claims. Omit the generic social-image fallback on helper-driven pages unless an actual absolute image is explicitly supplied.

Authoritative reference links used for water and rail guidance: HSE ACOP L8, HSE managing Legionella risk, Network Rail supplier assurance. These inform general guidance; they do not certify AFG's capabilities.
